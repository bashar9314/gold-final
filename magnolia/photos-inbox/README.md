# Photo inbox

Drop your original photos here, then run `npm run photos` (or just `npm run build`).

| File name                         | Where it appears                          |
|-----------------------------------|-------------------------------------------|
| `hero.jpg`                        | Full-screen hero background               |
| `before-1.jpg` + `after-1.jpg`    | Before/After slider #1 (repeat: -2, -3 …) |
| `pair-1.txt` (optional)           | Short caption for slider #1               |
| `gallery-final-kitchen.jpg` …     | Project gallery. Prefix with `gallery-`; optional category word: `final`, `rough`, `remodel`, `move-in`, `post-construction` |
| `uniform.jpg`                     | "Professional from site to finish" image  |

Use the SAME framing for a before/after pair so the slider lines up.
Originals are never served — optimized WebP copies (480–1920px) are generated automatically.
